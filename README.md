# 🎡 九宫格抽奖（Vue 3 + Vite）

一个经典的九宫格抽奖页面：3×3 网格，8 个奖品格子围绕四周，中间是抽奖按钮。点击按钮后高亮框按顺时针方向滚动 —— 起步短暂加速、长时间匀速、最后两圈二次曲线减速并停在抽中的奖品上，弹出中奖结果。

## 快速开始

```bash
npm install
npm run dev      # 启动开发服务器，默认 http://localhost:5173
npm run build    # 生产构建
```

> 如果本机 npm 默认缓存目录没有写入权限，可以像本项目一样加 `--cache .npm-cache` 把缓存放到项目内。

## 实现思路

1. **布局**：九宫格用 CSS Grid 渲染，行优先下标 `0~8`，下标 `4` 是中间按钮。
2. **奖池与采样**：配置文件提供 20 个奖品（全部配内置图片）的默认奖池；每轮开始时从池中**按权重不重复采样 8 个**作为本轮阵容，所以每轮阵容都不一样。池内没有"谢谢参与"之类的空奖，每次抽奖必中物品。
3. **槽位与路径统一**：8 个槽位按顺时针顺序排列（即 `PATH = [0, 1, 2, 5, 8, 7, 6, 3]`），采样阵容与停格计算共用同一套下标，保证"指针停在哪个格子，那个格子就是抽中的奖品"；每步用 `setTimeout` 链式调用移动高亮格。
4. **物品闪变（常驻华丽）**：闲置时全部 8 格每隔 220ms 各自随机切换显示池中图片，配合辉光波浪与错峰跳动动画，视觉上华丽炫目；点击抽奖后暂停闪变、锁定本轮阵容，滚动中仅高亮格快速闪变，开奖后定格 1.4 秒再恢复常驻闪变。
5. **图片化格子 + 开奖揭示**：九宫格平时只展示奖品图片、不显示名称；指针停下时，中奖格子才弹出红橙渐变的名称胶囊揭示结果，关闭弹窗后随闪变恢复自然隐去。
6. **先定结果再动画**：点击时先采样本轮阵容、再在其中按权重抽出中奖奖品，并计算需要滚动的总步数（至少整转 4 圈 + 对齐到目标的偏移量），动画走完自然停在结果上。
7. **变速曲线**：`getStepDuration()` 分三段 —— 前 4 步由 180ms 加速到 70ms；中段保持 70ms 匀速；最后两圈按二次曲线从 70ms 减速到最大 420ms，营造"擦着奖品滑过去"的悬念感。
8. **状态控制**：滚动中禁用按钮；次数用完显示"已用完"；中奖后弹出结果弹窗。

## 自定义奖品（页面内编辑）

编辑入口是一个**隐形按钮**：固定在**页面右上角**，平时完全透明不可见，把鼠标移到那个角落（或键盘聚焦）才会浮现 ✏️ 图标，点击打开编辑弹窗。适合"管理员暗门"式的使用场景——普通访客看不出入口，自己悬停即达。

对称地，**页面左上角**有一个同款隐形按钮 🔄：悬停显现，点击即**重置抽奖次数**（默认仅 1 次机会）。可以：

- **改名**：直接修改每个奖品的名称（最长 12 字）；
- **上传图片**：为任意奖品上传本地图片。图片会经过 canvas 等比压缩（最长边 160px、导出 WebP），以 dataURL 形式保存；
- **调权重 / 增删奖品**：每行可编辑权重（同时影响上格子与中奖概率），底部「＋ 添加奖品」扩充奖池，行尾 ✕ 删除（至少保留 8 个）；
- **移除图片 / 恢复默认**：一键回退。

所有改动**实时持久化**到浏览器 `localStorage`（键：`nine-grid-lottery/custom-prizes-v3`），刷新页面不丢失；删除奖品时，九宫格上对它的引用会被自动替换为池中随机奖品。若某个奖品暂时没有图片，格子会回落显示内置的盲盒占位图。

| 内容 | 来源 |
| --- | --- |
| 奖品名称、图片、权重、增删 | 页面编辑器 → localStorage |
| 默认奖池（20 个）与抽奖次数 | [prizeConfig.js](src/config/prizeConfig.js) 配置文件 |

localStorage 保存整个自定义奖池，「恢复默认」即还原为配置文件内容。加载时逐条清洗数据（名称为空、权重非法等自动兜底），不足 8 个时用默认奖品补齐。

## 如何自定义

### 换奖品 / 调概率

编辑 `src/config/prizeConfig.js`（这是"恢复默认"还原的基准奖池）：

```js
export const defaultPrizePool = [
  { id: 101, name: 'iPhone', weight: 2, image: wupin(1) },
  // ... 共 20 个、全部配图（src/assets/img/wupin/1.png ~ 20.png 按编号对应）；
  // weight 同时影响"被抽上格子"和"最终中奖"的概率
]

export const TOTAL_DRAWS = 1 // 初始抽奖次数（仅一次；左上角隐形 🔄 按钮可重置），Infinity 表示不限次
```

- `name` 直接改文案；图片与奖品名的对应关系改 `wupin(n)` 编号即可；
- 奖池没有空奖：去掉某个"谢谢参与"类条目后，每次抽奖都会中实物；
- 奖池数量只要 ≥ 8 个，每轮都会随机抽 8 个上格子。

### 接入真实后端接口

抽奖结果通常应由服务端决定。只需把 `startRoll()` 里的 `pickPrizeIndex()` 换成一次异步请求：

```js
const targetPrizeIndex = await api.draw() // 后端返回 prizeList 的下标
```

注意在请求期间保持 `rolling = true` 以防重复点击。

### 调节手感

`NineGridLottery.vue` 顶部的常量可随意调整：

| 常量 | 含义 | 默认值 |
| --- | --- | --- |
| `FAST_MS` | 匀速阶段每步间隔 | 70ms |
| `START_MS` | 起步第一步间隔 | 180ms |
| `MIN_LOOPS` | 至少完整滚动圈数 | 4 |
| `SLOW_DOWN_CELLS` | 最后减速的步数 | 16（两圈） |
| `MAX_SLOW_MS` | 减速末端最大间隔 | 420ms |
